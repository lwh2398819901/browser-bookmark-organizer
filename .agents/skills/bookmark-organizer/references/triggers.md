# 触发词与授权边界

## 意图路由

| 触发词 | 选择模式 | 默认输出 |
|---|---|---|
| 整理收藏夹、首次整理收藏夹、全量整理、全量审计 | 首次整理 | 审计和可复核建议，不改动 |
| 整理临时收藏夹、归档临时收藏、处理临时收藏 | 临时收藏归档 | 精确去重和移动计划，不改动 |
| 检查重复收藏、收藏夹去重、找重复链接 | 重复检查 | 精确重复与关联链接报告 |
| 检查失效链接、检查链接变化、链接健康检查 | 链接健康 | 可用性与变化报告 |
| 收藏夹画像、分析我的收藏夹、深度画像 | 收藏夹画像 | HTML 统计与 AI 语义解读 |
| 执行移动计划、应用归档计划、按方案移动 | 应用计划 | 校验并通过扩展移动 |

## 明确授权要求

- “整理”“清理”“归档”默认不删除、不移动实时浏览器收藏。
- “执行”“应用”“移动”只允许执行已展示且获确认的移动计划。
- “删除”“移除”“清空”必须先展示逐项清单并获得本轮明确授权。
- 失效或无法确认链接均不得直接删除。
