# 工作流与触发词

## 默认安全策略

任何“整理”请求先生成审计和计划；只有“执行移动计划”“应用归档计划”等明确说法才可以移动书签。删除需要单独、明确授权。每次通过扩展执行移动时，扩展会先导出完整收藏夹归档；归档失败则不移动任何书签。

| 模式 | 触发词示例 | 输出 | 是否改动浏览器 |
|---|---|---|---|
| 首次审计 | 整理收藏夹、首次整理、全量审计 | 目录/重复/质量报告和建议 | 否 |
| 临时归档 | 整理临时收藏夹、归档临时收藏 | 去重结果和逐项移动计划 | 否 |
| 重复检查 | 检查重复收藏、收藏夹去重 | 精确重复列表 | 否 |
| 链接健康 | 检查失效链接、检查链接变化 | 可用/不可用/无法确认清单 | 否 |
| 深度画像 | 收藏夹画像、深度画像 | HTML 统计层与 AI 证据解读 | 否 |
| 应用计划 | 执行移动计划、应用归档计划 | 完整 HTML 归档、扩展校验与移动结果 | 是，先归档后移动 |

## 分类原则

- 精确 URL 相同才是自动去重候选。
- URL 仅片段（`#`）不同通常代表章节，属于关联链接而非重复。
- 动态资讯、博客、AI 产品和在线工具可纳入定期复核；基础知识、官方文档和长期参考资料默认保留。
- HTTP 401、403、429、5xx、超时、登录页和机器人拦截都只标记为“无法确认”。链接检查默认对同一域名限速，并对临时错误进行有限次数的退避重试。

## AI 语义层

AI 先阅读命令生成的 `ai-profile-brief.md`，必要时再读少量代表页面。输出必须附带书签证据，内容仅限知识主题、信息结构、资料使用习惯和维护建议；不得推断敏感属性。
