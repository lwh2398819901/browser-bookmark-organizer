# 工作流与触发词

## 默认安全策略

任何“整理”请求都先明确范围并生成可复核计划，但不都需要全量审计。临时收藏优先使用 `bookmarkctl scan` 通过扩展实时扫描；首次全量整理、画像和链接健康检查才运行审计脚本。用户已明确范围、目标和移动意图，或确认当前预览后，Agent 可用 `apply-plan --confirmed` 移动书签。删除需要单独、明确授权。每次通过扩展执行移动时，扩展会先导出完整收藏夹归档；归档失败则不移动任何书签。

正常日常整理的扩展调用为 `scan → validate-plan → apply-plan`。最后一步已经强制先备份，不得在整理前另调 `backup`；`status` 仅用于故障诊断，`archives` 和 `operations` 仅用于用户查询或不确定结果核对。命令超时或输出丢失时先查询实际状态，不能直接重试写入命令。

| 模式 | 触发词示例 | 输出 | 是否改动浏览器 |
|---|---|---|---|
| 仅备份 | 备份我的收藏夹、先归档一下、什么都别改只导出一份 | 完整可导入 HTML、保存路径与条目统计 | 否 |
| 首次审计 | 整理收藏夹、首次整理、全量审计 | 目录/重复/质量报告和建议 | 否 |
| 临时归档 | 整理临时收藏夹、归档临时收藏 | 去重结果和逐项移动计划 | 否 |
| 重复检查 | 检查重复收藏、收藏夹去重 | 精确重复列表 | 否 |
| 链接健康 | 检查失效链接、检查链接变化 | 可用/不可用/无法确认清单 | 否 |
| 深度画像 | 收藏夹画像、深度画像 | HTML 统计层与 AI 证据解读 | 否 |
| 应用计划 | 执行移动计划、应用归档计划 | 完整 HTML 归档、扩展校验与移动结果 | 是，先归档后移动 |
| 删除候选 | 整理时这些可以删、过期页清掉 | 移入 `待删除`，请用户手工删除 | 是，先归档后移动 |
| 收尾待删除 | 删完了、待删除处理过了 | 剩余条目放回合适目录；文件夹已空则删除它 | 是，先归档后变更 |
| 删除书签 | 删掉这些、清掉失效收藏 | 默认移入回收站的预览；永久删除需另一次明确授权 | 是，先归档后变更 |
| 清理空目录 | 删掉空文件夹、目录壳太多 | 空目录清单；确认后删除并可撤销重建 | 是，先归档后变更 |
| 调整目录 | 重命名目录、把这个文件夹移到最后 | 目录预览；确认后重命名或移动 | 是，先归档后变更 |
| 撤销整理 | 撤销上次整理、放回原目录 | 撤销前备份、按操作记录移回原位置 | 是，先归档后移动 |

## 插件日常入口

- Agent 日常入口是技能中的 `scripts/bookmarkctl.py`，不是插件页面。`scan`、`backup`、`archives`、`operations`、`validate-plan`、`apply-plan` 和 `undo` 通过本地桥接调用扩展。
- 命令执行时只短暂监听 `127.0.0.1` 的随机端口，并打开一个完成即关闭的本地桥接小窗口；不需要用户点击、复制或粘贴。

- 工具栏小窗口用于把当前网页加入 `临时收藏`、对已收藏页面显示“取消收藏”，以及一键备份。取消收藏直接删除当前页的规范化匹配，不进入回收站。收藏或备份成功后自动收起，备份由后台完成，不再打开整理中心新标签页。
- “整理中心”展示临时收藏、仍在磁盘上的最近 30 份备份、可视化移动方案和最近 20 次插件操作记录；已删除或移动的备份不会继续显示。
- 备份列表中的每一份都可以单独“删除备份”：用户点击后直接删除该备份文件，不再二次弹窗，也不改动收藏夹。
- 插件页面中的勾选、复制给 Agent 和粘贴 JSON 保留为人工备用功能。自动流程应直接调用本地命令，不使用视觉自动化。
- 用户可以直接粘贴 Agent 的整段回复，插件会从纯 JSON、Markdown 代码块或带说明的回复中提取方案；最终应以校验后的逐条移动预览为准。
- “撤销本次整理”恢复插件记录的移动、软删除、目录重命名和目录移动；永久删除会按记录重建，运行时 ID 会改变。撤销不会删除整理时创建的空目录。HTML 深度恢复由浏览器原生导入完成。
- “清空记录”只移除插件本地操作历史，不修改收藏夹，也不删除任何备份文件。

## 分类原则

- 整理时认为可以删除的书签移入收藏夹栏下已有的 `待删除`；没有该目录时才新建。用户说删完后，剩余条目放回合适位置；目录已空则只用 `--path` 删除它。清理某一支的空目录用 `--empty --path`，要保留的空目录用重复的 `--exclude`。
- 精确 URL 相同才是自动去重候选。多余副本可以进入 `待删除`。
- URL 仅片段（`#`）不同通常代表章节，属于关联链接而非重复。
- 动态资讯、博客、AI 产品和在线工具可纳入定期复核；基础知识、官方文档和长期参考资料默认保留。
- HTTP 401、403、429、5xx、超时、登录页和机器人拦截都只标记为“无法确认”。链接检查默认对同一域名限速，并对临时错误进行有限次数的退避重试。

## AI 语义层

全量画像时，AI 先阅读命令生成的 `ai-profile-brief.md`，必要时再读少量代表页面；日常临时收藏分类则直接使用扩展任务。输出必须附带书签证据，内容仅限知识主题、信息结构、资料使用习惯和维护建议；不得推断敏感属性。
