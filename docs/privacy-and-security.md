# 隐私与安全

- 收藏夹解析、去重、HTML 画像和移动计划在本机进行。
- Agent 桥接只在单次命令期间监听 `127.0.0.1` 的随机端口，通过安装时生成的随机令牌和固定扩展 ID 校验请求；不监听局域网地址，不长期运行，也不向远端服务发送收藏夹。
- 本地令牌保存在 `~/.bookmark-organizer/bridge.json` 和已安装扩展副本的 `bridge-config.js` 中，不提交到 Git。重新安装优先从已部署扩展恢复令牌并同步 CLI 配置；`doctor.ps1` 只比较两侧是否一致，不显示令牌内容。
- Chromium 扩展请求四项权限：`bookmarks` 用于扫描、收藏和移动；`downloads` 用于创建、显示并按保留规则清理本扩展生成的备份 HTML；`activeTab` 仅在用户点击扩展时读取当前网页的标题和网址；`storage` 仅在本地保存最近的插件整理记录以支持撤销。扩展不含网站访问权限、不注入网页、不读取浏览历史。
- 备份（工具栏小窗口的“立即备份”或整理中心的“一键备份收藏夹”）只读取收藏夹树并下载 HTML，不创建目录、不移动、不删除或修改任何书签。
- 每次执行移动前，扩展会导出包含收藏夹栏等根目录语义及时间属性的完整 HTML。只有该归档下载完成，移动才会开始；自动保留专属归档目录中符合严格命名规则的最近 30 份。清理不依赖可能因扩展目录变化而改变的扩展 ID。
- 用户可以手动删除指定的某一备份；该操作只删除这个备份文件本身，不改动收藏夹，并且需要用户二次确认。“清空记录”只删除本地保存的操作历史，不修改收藏夹，也不删除任何备份文件。
- 链接健康检查会访问书签网址，可能被目标站点记录为普通浏览器请求。请仅在同意该行为时使用 `--check-links`。
- 不要提交真实浏览器 `Bookmarks` 文件、HTML 导出、报告或包含敏感网址的截图。
- 自动化只能应用明确批准的移动计划；删除和批量清理应始终让用户复核。
- HTML 恢复使用浏览器原生导入功能。插件只显示备份文件和恢复步骤，不会为了恢复而自动清空或覆盖当前收藏夹。
