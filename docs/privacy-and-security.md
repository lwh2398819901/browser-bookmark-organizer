# 隐私与安全

- 收藏夹解析、去重、HTML 画像和移动计划在本机进行。
- Edge 扩展请求 `bookmarks` 和 `downloads` 权限：前者用于扫描和移动，后者仅用于在浏览器下载目录创建、核验并按保留规则清理本扩展生成的归档 HTML；不含网络权限、不注入网页、不读取浏览历史。
- “仅备份当前收藏夹”只读取收藏夹树并下载 HTML，不创建目录、不移动、不删除或修改任何书签。
- 每次执行移动前，扩展会导出包含收藏夹栏等根目录语义及时间属性的完整 HTML。只有该归档下载完成，移动才会开始；自动保留专属归档目录中符合严格命名规则的最近 30 份。清理不依赖可能因扩展目录变化而改变的扩展 ID。
- 链接健康检查会访问书签网址，可能被目标站点记录为普通浏览器请求。请仅在同意该行为时使用 `--check-links`。
- 不要提交真实浏览器 `Bookmarks` 文件、HTML 导出、报告或包含敏感网址的截图。
- 自动化只能应用明确批准的移动计划；删除和批量清理应始终让用户复核。
