备份与恢复

给当前状态留一份保险

一键导出完整 HTML；本扩展自动维护最近 30 份。

从这份 HTML 恢复

  1. 先保留当前状态：如有需要，再点一次“一键备份收藏夹”。
  2. 点击对应备份的“显示文件”，在资源管理器中找到 HTML。
  3. 打开浏览器的“导入浏览器数据”，选择“收藏夹或书签 HTML 文件”。
  4. 导入会与当前收藏夹合并；导入后检查是否出现重复目录。

浏览器没有向扩展开放原生 HTML 导入接口，因此这里不会自动清空或覆盖当前收藏夹。

使用 Agent 自动分类

只有希望 Agent 阅读网页并自动判断目录时才需要这里；手动归类可以忽略本区域。

  1. 先在上方扫描临时收藏，然后点击“复制整理任务给 Agent”。
  2. 切换到已安装本技能的 Agent，粘贴任务并让它完成分析。
  3. 把 Agent 的整段回复粘贴到下方，再生成可视化预览。
