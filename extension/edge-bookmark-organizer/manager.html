怎么用这个插件和 Agent

收藏和备份用插件自己点。整理、检查、画像和撤销，在已经装好本技能的 Agent 里用白话说。Agent 通过本机扩展读取收藏夹，不会把收藏夹上传出去。

工具栏

  • 点扩展图标。这一页还没收藏时，按钮是「加入临时收藏」，会放进收藏夹栏的「临时收藏」。
  • 这一页已经收藏时，按钮变成「取消收藏」。它会删掉这个网址的全部匹配，不进回收站，也不能撤销。旁边会写明它在哪个目录。
  • 如果这个网站还收过别的页面，点「同站已有…」那一行可以展开。带下划线的标题可以点开网页。
  • 下面的「重复链接」是全库里同一个网址存了不止一次。点开能看到分别在哪些目录，也可以在这里取消收藏。
  • 「立即备份」会先弹出名称。默认是当前时间，可以改，也可以直接确定。取消则这次不备份。

这个页面

  • 上面四个数字是当前收藏夹的概况：全部书签、文件夹、临时收藏、还在磁盘上的备份份数。
  • 「立即备份」和工具栏是同一件事，成功后列表会自己刷新。名称写在每一行最上面，可以直接改。
  • 「显示文件」在资源管理器里定位那份 HTML。「删除备份」只删文件，不改收藏夹。
  • 「清空 7 天前的备份」或填一段日期，只删除这个时间范围内的备份文件。
  • 「恢复这份备份」会问要不要先把现在的收藏夹存下来。选「先备份再恢复」会再要一次名称；选「直接恢复」就用该文件替换当前收藏夹，不另存。恢复不是合并，是整份换回去。

跟 Agent 怎么说

不用记命令。打开 Agent，直接说你要做什么。它会先看现有目录和链接，只有看不准的才打开网页。要改收藏夹时，会先给你方案，你同意后才移动。

  • 「整理临时收藏」：处理刚存进收件箱的书签，和全库比过重复后，建议放到已有或新建目录。
  • 「整理收藏夹」或「第一次收拾」：先做全量审计和建议，不立刻改。
  • 「把这些移到某某目录」：范围和目标已经明确时，核对后移动。
  • 「检查重复」：同一个网址算重复。只有 # 后面不同的，当成不同章节，不合并。
  • 「检查失效链接」或「网站还活着吗」：会访问这些网址。确认打不开的是 404、410。超时、要登录、被拒绝访问，只记成无法确认，不当成失效。
  • 「收藏夹画像」或「我都关注什么」：生成一份 HTML 画像。结论要有书签证据，不推断个人情况。
  • 「撤销上次整理」：按插件记下的那一次操作，把书签移回原来的目录。这个页面上没有撤销按钮。
  • 「删完了」：你手工处理完「待删除」之后再说。里面还有书签就放回合适目录；空了就删掉这个文件夹。

删除时怎么处理

  • 整理中觉得可以删的，例如过期活动、一次性兑换码、已确认打不开且没有长期用处的页面，会移到收藏夹栏的「待删除」。由你在浏览器里删，不由助手直接删掉。
  • 你点名「删掉这几条」时，默认移进「回收站」，还可以撤销。只有你明确说永久删除，才会真的删掉。
  • 工具栏的「取消收藏」是例外：它直接删除当前页，不进回收站。
