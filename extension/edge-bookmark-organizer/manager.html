怎么用

插件

  • 点工具栏图标。当前页没收藏时，加入「临时收藏」；已经收藏时，按钮是「取消收藏」，并显示它在哪个目录。
  • 同站还有别的收藏时，点那一行可以展开，再点标题就打开那个网页。重复链接也可以在这里展开后取消收藏。
  • 工具栏和本页的「立即备份」都会先弹出名称。默认是当前时间，可以改，也可以直接确定。
  • 备份列表里的名称可以直接改。每份备份可以显示文件、恢复或删除。也可以按天数或日期清空旧备份。
  • 点「恢复这份备份」后，可以选择先备份现在的收藏夹，或直接用该文件替换。不备份也可以恢复。

Agent

在已经能读到本技能的 Agent 里直接说目标。它会通过本机扩展读取收藏夹；要移动时会先给你看方案，你同意后才执行。

  • 整理临时收藏，或把刚存的归类。
  • 整理整个收藏夹。
  • 检查重复、检查失效链接、生成收藏夹画像。
  • 把指定的书签移到某个目录。
  • 撤销上次整理。撤销不在这个页面上，跟 Agent 说即可。

可以删的书签会集中到收藏夹栏的「待删除」，由你在浏览器里手工删除。删完后告诉 Agent，它再收尾。
